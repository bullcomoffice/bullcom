年の初めは、普段見ないところを見直すのに適したタイミングです。神戸・明石のBULLCOMでは、セキュリティの問題は「気づいた時にはもう遅い」というケースをよく見ます。年に一度でいいので、確認しておいてください。5分で終わる項目から順に並べました。

5分でできる4項目

① Windows Updateの状態

設定 → Windows Update

「最新の状態です」と表示されているか確認します。保留中の更新があれば適用してください。

更新が止まったまま何か月も経っている——これは実際によくある状態です。更新はセキュリティの穴を塞ぐためのものなので、放置は危険です。

なお、Windows 10のサポートは終了しています。まだWindows 10なら、この機会に移行を検討してください。

② ウイルス対策の状態

設定 → プライバシーとセキュリティ → Windowsセキュリティ

すべての項目に緑のチェックが付いているか確認します。

市販ソフトをお使いなら、契約の有効期限も確認してください。期限切れのソフトが入ったままが最も危険な状態です——標準のDefenderが無効化されたまま、市販ソフトも機能していないからです。

使わないなら、アンインストールしてDefenderを有効に戻してください。

③ バックアップの状態

外付けHDDやクラウドを実際に開いて、最新のデータが入っているか確認します。

「自動で取れているはず」が、エラーで何か月も止まっていた——これも実際によくあります。中身を見るまで、取れているかは分かりません。

④ 使っていないアプリの整理

設定 → アプリ → インストールされているアプリ

古いまま放置されたソフトは、セキュリティの穴になります。使っていないものは削除してください。特に、

  • サポートが終了した古いソフト
  • 何のソフトか分からないもの（ただし、システム関連は残す）

パスワードの棚卸し（15分）

使い回しをやめる

同じパスワードを複数のサービスで使っていると、1つ漏れた時点ですべてが危険になります。実際、流出したIDとパスワードの組み合わせで他のサービスに侵入する攻撃は日常的に行われています。

最低でも、次の3つは他と違うパスワードにしてください。
メール（ここが破られると、他のパスワードもリセットされてしまいます）ネットバンキングショッピングサイト（カード情報が登録されているもの）
2段階認証を有効にする

パスワードに加えて、スマホへの通知やコードで確認する仕組みです。

これを有効にしておけば、パスワードが漏れても侵入を防げます。最も効果の高い対策です。

優先して設定すべきサービス：
メール（Gmail、Outlook等）Microsoftアカウント、GoogleアカウントネットバンキングSNS
パスワード管理を仕組みにする

すべてを記憶するのは無理です。

  • パスワード管理ソフトを使う
  • 紙に書いて、安全な場所に保管する（意外と現実的な方法です）
  • ブラウザの保存機能を使う場合は、パソコン自体にロックをかけておく

その場で確認したいこと

ブラウザの拡張機能

使っていない拡張機能を削除してください。拡張機能は閲覧内容を読み取れるため、信頼できないものが入っていると情報が漏れます。動作も重くなります。

心当たりのないログイン履歴

Microsoftアカウント・Googleアカウントには、ログイン履歴の確認画面があります。心当たりのない場所からのログインがあれば、すぐにパスワードを変更してください。

メールの自動転送設定

メールが第三者に自動転送される設定を仕込まれる——実際にある手口です。心当たりのない転送ルールが設定されていないか確認してください。

家族と共有しておきたいこと

技術的な設定より効くことがあります。

> 「画面に電話番号が出ても、絶対にかけない」

サポート詐欺の被害は、この一言で大半が防げます。「ウイルスに感染しました」という警告画面と警告音が出て、表示された番号に電話をかけてしまう——これが典型です。

あわせて、
警告音は電源ボタンの長押しで止めてよいお金を払う前に必ず家族に相談する「今すぐ」「至急」と急かすものは全部疑ってよい
ご高齢のご家族には、特に伝えておいてください。

法人の場合、追加で確認したいこと

  • 退職者のアカウントが残っていないか
  • 共有フォルダのアクセス権が適切か
  • 業務PCのウイルス対策が全台で有効か
  • バックアップからの復旧を実際に試したことがあるか

最後の項目が重要です。バックアップは「取れていること」より「**戻せること**」が本質です。試したことがなければ、一度検証しておいてください。

BULLCOMのサポート

  • セキュリティ点検（持ち込み診断は無料）
  • ウイルス感染の診断・駆除（ウイルス診断 ¥8,800〜）
  • バックアップ体制の構築
  • 法人のセキュリティ整備、アカウント棚卸し
  • 神戸市・明石市へ出張対応（出張エリアA・¥5,500〜）

**「感染しているか分からない」という段階でのご相談**を歓迎します。手遅れになる前が最も対処しやすいタイミングです。[神戸市](/area/kobe)・[明石市](/area/akashi)へ伺います。

まとめ

まず5分で、Windows Update・ウイルス対策・バックアップ・不要アプリの4項目を確認してください。

そして最も効果が高いのが、メールアカウントの2段階認証です。メールを守れば、他のサービスのパスワードリセットも守られます。ここだけは今日中に設定する価値があります。

最後に、ご家族へ「画面に電話番号が出ても絶対にかけない」と伝えておいてください。技術的な設定より、この一言のほうが被害を防ぎます。
