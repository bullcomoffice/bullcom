「社内のパソコンを何台か入れ替えたいが、業務を止めずにどう進めればいいか」——神戸・明石の事業所様から、Windows 10のサポート終了以降とくに増えているご相談です。入れ替えで失敗する原因は、機種選定ではなく段取りにあります。実務で押さえるべき手順を整理しました。

失敗の典型パターン

先に、よくある失敗を挙げます。

  • 新しいPCを配ったが、業務ソフトが動かず旧PCに戻した
  • データは移したが、メールの過去分が消えた
  • Officeのライセンスが移せず、買い直しになった
  • 旧PCを処分したあとに、必要なファイルが見つかった
  • 全台まとめて交換し、その日一日業務が止まった

いずれも事前の確認で防げるものばかりです。

ステップ1：現状を把握する

まず「何が動いていて、何が必要か」を洗い出します。台数が少なくても、紙に書き出す価値があります。

| 確認項目 | 見るポイント |
|---|---|
| 使用中のソフト | 会計・給与・販売管理など。新OS対応か |
| ライセンス | Office、業務ソフトの認証方式と移行可否 |
| 周辺機器 | プリンター・複合機・スキャナのドライバ対応 |
| データの場所 | ローカル保存かサーバーか。デスクトップに直置きが要注意 |
| メール | 受信方式（POP/IMAP）と過去メールの保管場所 |
| 使用者 | 誰がどのPCを使い、何に使っているか |

最大の落とし穴は業務ソフトの対応確認です。メーカーのサイトで新OS対応を確認し、記載がなければ問い合わせてください。「動くはず」で進めると、配った後に戻す羽目になります。

ステップ2：ライセンスを確認する

Officeは購入形態によって扱いが変わります。

  • Microsoft 365（サブスク）：アカウントでサインインすれば新PCで使えます。移行は容易
  • 永続版（買い切り）：プロダクトキーが必要。PCにプリインストールされていたものは移行不可が原則
  • ボリュームライセンス：契約内容の確認が必要

「前のPCに入っていたOfficeを新しいPCに移す」は、購入形態によってはできません。ここを見落とすと、追加費用が発生します。

ステップ3：メールの移行方針を決める

トラブルが最も多い箇所です。

  • IMAP・Microsoft 365 の場合：サーバー側にメールがあるため、設定するだけで過去分も同期されます
  • POPの場合：パソコン内にしかメールがありません。データファイルの移行が必須です

POP運用の場合、旧PCを処分した時点で過去のメールは失われます。移行前に必ずデータの場所を確認してください。この機会にIMAPへ切り替えるのも一案です。

ステップ4：段階的に入れ替える

全台を一度に交換しないでください。

  1. まず1台だけ入れ替えて、1週間ほど通常業務で使ってもらう
  2. 問題が出れば、その時点で対処する
  3. 問題がなければ、残りを数台ずつ進める

この方法なら、想定外の問題が起きても業務が止まりません。台数が多いほど効果があります。

ステップ5：旧PCはすぐ処分しない

最低1か月は保管してください。「あのファイルが見つからない」は必ず起きます。

保管期間が過ぎたら、
データ消去を実施（初期化だけでは不十分です）法人の場合はデータ消去証明書を取得認定業者で回収
入れ替えのタイミング

業務への影響を抑えるなら、次の時期が向いています。

  • 月初・月末の締め処理を避ける
  • 決算期・繁忙期を避ける
  • 金曜の午後に作業し、週末に予備日を確保する

年末は締め処理と重なるため、**11月までに終えておく**のが理想です。

BULLCOMの法人サポート

  • 現状の棚卸し、業務ソフトの対応確認
  • 機種選定のご相談（用途に合わせた仕様の提案）
  • 初期設定・データ移行・メール設定
  • 周辺機器の接続、ネットワーク設定
  • 旧PCのデータ消去・回収（証明書の発行も可能）
  • リモートサポート契約（年額¥11,000〜）

神戸市・明石市の事業所様へは出張対応しています（出張エリアA・¥5,500〜）。台数が多い場合は事前の打ち合わせから承ります。[神戸市](/area/kobe)・[明石市](/area/akashi)のページもご覧ください。

まとめ

入れ替えの成否は段取りで決まります。①現状把握 ②ライセンス確認 ③メールの移行方針 ④1台ずつ段階的に ⑤旧PCは1か月保管——この順で進めれば、業務を止めずに移行できます。

とくに業務ソフトの新OS対応と、POPメールの扱いは事前確認が必須です。ご相談は無料ですので、計画段階でお声がけください。
