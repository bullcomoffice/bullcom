「昨日まで使えていたスキャンが、急にパソコンに取り込めない」「読み取った文字がかすれて読めない」——事務作業が止まるため、法人様からのご相談が多いトラブルです。神戸・明石のBULLCOMでも定期的に承ります。「取り込めない」と「画質が悪い」では原因がまったく違うので、分けて考えます。

パソコンに取り込めない場合

まず確認：どこまで動いているか

| 状況 | 疑わしい原因 |
|---|---|
| 複合機側の操作パネルでエラーが出る | 機器側の問題（紙詰まり、インク等） |
| スキャンは実行されるがPCに届かない | ネットワーク・保存先の設定 |
| PC側からスキャンを開始できない | ドライバ、接続 |
| 印刷はできるがスキャンだけ不可 | スキャン用ドライバ・設定の問題 |

「印刷はできるのにスキャンだけできない」は非常に多いパターンです。印刷とスキャンは別々の仕組みで動いているため、片方だけ壊れることがあります。

ネットワーク接続の複合機の場合

もっとも多い原因がIPアドレスの変更です。

複合機のIPアドレスが自動取得（DHCP）になっていると、ルーターの再起動などでアドレスが変わってしまうことがあります。パソコン側は古いアドレスを覚えたままなので、繋がらなくなります。

確認方法
複合機の操作パネルで、現在のIPアドレスを確認（設定 → ネットワーク設定 等）パソコンに登録されているアドレスと一致しているか確認
根本対策：複合機のIPアドレスを固定に設定してください。これで再発しなくなります。法人で複数台から使う環境では、ほぼ必須の設定です。

USB接続の場合

  • 別のUSBポートに挿す
  • ケーブルを別のものに替える
  • USBハブ経由ならパソコンに直挿し

ドライバを入れ直す

メーカーのサイトから、**お使いのWindowsバージョンに対応したドライバ**を入手して再インストールしてください。Windows 11に更新した後にスキャンだけ使えなくなった、というケースはよくあります。

保存先フォルダの確認

「スキャンして共有フォルダに保存」の設定を使っている場合、

  • 保存先のフォルダ名・パスが変わっていないか
  • 共有設定・アクセス権が外れていないか
  • パソコンのパスワードを変更していないか（認証に失敗します）

**パソコンのパスワードを変えた後にスキャンが届かなくなる**——これも定番のご相談です。

画質が悪い場合

文字がかすれる・薄い

  • 解像度を上げる（文書なら300dpi、写真なら600dpi以上）
  • 濃度設定を上げる
  • 原稿台のガラスを清掃する（指紋や汚れが写ります）

線や汚れが入る

  • 原稿台のガラスを柔らかい布で拭く
  • 自動原稿送り装置（ADF）の読み取り部を清掃する

- 縦一直線に線が入る場合、ほぼここが原因です

「毎回同じ位置に線が入る」なら、ガラスかローラーの汚れで確定です。

色がおかしい

  • カラー/グレースケール/白黒の設定を確認
  • 「自動判別」が誤動作していないか

ファイルサイズが大きすぎる

  • 解像度を下げる（文書なら200〜300dpiで十分）
  • カラーではなくグレースケールにする
  • PDFの圧縮設定を見直す

スキャンした文字を検索・コピーしたい

スキャンしたPDFは、そのままでは文字が画像として保存されているため検索できません。OCR（文字認識）の処理が必要です。

  • 複合機に「検索可能なPDF」機能があれば有効化する
  • Acrobat Pro等のソフトで後から処理する

法人で書類を電子化する場合、この設定をしておくと後の検索性がまったく変わります。

給紙まわりのトラブル

  • 紙詰まりが増えた → 給紙ローラーの摩耗。清掃または交換
  • 複数枚を一度に吸い込む → 同上。紙をよくさばいてセットする
  • 斜めに読み取られる → ガイドの位置を調整

BULLCOMのサポート

  • スキャン・複合機の接続トラブルの診断
  • ドライバの再設定、IPアドレスの固定化
  • 共有フォルダへの保存設定
  • 法人の複合機とPCの連携設定
  • 神戸市・明石市へ出張対応（出張エリアA・¥5,500〜）

**複合機まわりは現地での確認が必要**なため、出張での対応をおすすめします。[神戸市](/area/kobe)・[明石市](/area/akashi)へ伺います。

まとめ

「取り込めない」場合、ネットワーク接続ならIPアドレスの変更を最初に疑ってください。固定IPにしておけば再発しません。「印刷はできるのにスキャンだけ」なら、スキャン用ドライバか保存先の設定です。

「画質が悪い」場合は、解像度の設定とガラス面の清掃でほとんど解決します。縦線が入るならADFの読み取り部を拭いてみてください。
