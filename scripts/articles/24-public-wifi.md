カフェや駅、ホテルで使える無料Wi-Fi。便利ですが、「危ない」と聞いて不安に感じている方も多いと思います。神戸・明石のBULLCOMでもよく聞かれるご質問です。**結論から言うと、危険は確かにありますが、やってはいけないことを避ければ日常的な用途は問題ありません。**線引きを整理します。

## 何が危険なのか

公衆Wi-Fiのリスクは主に3つです。

### ① 通信の盗み見
暗号化されていないWi-Fiでは、同じネットワークにいる第三者が通信内容を覗ける可能性があります。ただし現在は**ほとんどのサイトがHTTPSで暗号化**されているため、このリスクは以前より下がっています。

### ② 偽のアクセスポイント
これが最も現実的な脅威です。攻撃者が店名に似せた名前のWi-Fiを用意し、接続してきた人の通信を中継して盗み見る手口です。

> 本物：`Cafe_FREE_WiFi`
> 偽物：`Cafe_FREE_WiFi_2` `Free_WiFi_Cafe`

**見た目では判断できません。**店員に正式な名前を確認するのが確実です。

### ③ 同じネットワーク上の端末からの侵入
共有設定がオンのままだと、同じWi-Fi内の他の端末からパソコンが見えてしまうことがあります。

## 接続時に必ずやる設定

Windowsでは、接続時に「このネットワーク上の他のデバイスに、このPCを検出させますか？」と聞かれます。

**公衆Wi-Fiでは必ず「いいえ」を選んでください。**

すでに接続済みの場合は、

**設定 → ネットワークとインターネット → Wi-Fi → （接続中のネットワーク）→ ネットワークプロファイルの種類 → 「パブリック」**

「プライベート」になっていると、他の端末から見える状態です。

## やってはいけないこと

| やってはいけない | 理由 |
|---|---|
| **ネットバンキングを使う** | 万一の被害が金銭に直結します |
| クレジットカード情報の入力 | 同上 |
| 業務の機密ファイルの送受信 | 会社の情報漏えいになりえます |
| 「証明書エラー」を無視して進む | **中間者攻撃の典型的な兆候です** |
| 自動接続を有効にしたままにする | 偽のAPに勝手に繋がります |

とくに4つ目。ブラウザが「この接続ではプライバシーが保護されません」と警告した場合、**絶対に「続行」を押さないでください。**通信を横取りされているサインの可能性があります。

## やっても問題ないこと

過度に怖がる必要はありません。次の用途なら、通常は問題ありません。

- ニュースサイト・ブログの閲覧
- 地図・乗換案内の利用
- HTTPS接続のWebサイトの閲覧
- 動画の視聴

「鍵マーク（HTTPS）が付いたサイトを見るだけ」なら、実用上のリスクは低いと考えて差し支えありません。

## より安全にする方法

### スマホのテザリングを使う
**最も確実な対策です。**自分のスマホの回線を使うため、公衆Wi-Fiのリスクを丸ごと回避できます。重要な作業をするなら、これが一番です。

### VPNを使う
通信全体を暗号化する仕組みです。ただし選び方に注意が必要です。

- **無料VPNは避けてください。**通信内容を収集・販売しているものがあります
- 有料の信頼できるサービスを選ぶ

### 自動接続を切る
**設定 → ネットワークとインターネット → Wi-Fi → 既知のネットワークの管理**

使い終わった公衆Wi-Fiは削除し、「自動的に接続する」のチェックを外しておきます。これをしておかないと、外出先で似た名前の偽APに勝手に繋がることがあります。

## 使い終わったらやること

- Wi-Fiをオフにする
- 「既知のネットワーク」から削除する
- 共有設定を確認する

## ホテルのWi-Fiも同じ

出張時のホテルWi-Fiも公衆Wi-Fiと同じ扱いです。むしろ**宿泊者しか使えないという安心感から油断しやすい**ぶん、注意が必要です。業務データを扱うなら、テザリングかVPNを使ってください。
