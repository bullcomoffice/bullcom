「Windows 11 は、2027年の秋に久しぶりの大型更新を迎えるらしい」——11月上旬、海外のIT系メディアがそう伝えました。今年の 26H2 は小さな更新で済みましたが、来年は少し様子が違うかもしれません。この記事では、報じられている内容と、今のパソコンを使い続けるうえで知っておきたいことを、神戸・明石のパソコン修理店 BULLCOM がまとめました。

※2026年11月8日時点の報道をもとにしています。**Microsoft は 27H2 をまだ正式に発表していません。**

## 何が報じられたのか

米国の The Verge（Tom Warren 氏）と Windows Central（Zac Bowden 氏）が伝えた内容は、おおむね次のとおりです。

- Microsoft は、2027年の **Windows 11 バージョン 27H2** の準備を進めている
- 27H2 は、**OSの土台となる部分（コアOS）を入れ替える大型の更新**になる見通し。コアOSの入れ替えは、2024年の 24H2 以来
- 新しい機能を増やすことよりも、**品質の改善（安定して動くこと）に重点**が置かれている
- Windows 12 として出すのではなく、**Windows 11 の改善を続ける形**に見える
- 配信は、例年の大型更新と同じ **2027年9〜10月ごろに始まり、段階的に広げられる**見込み

一方で、**対応するCPUなど、動かすための条件（動作要件）が変わるかどうかは伝えられていません**。

## 25H2・26H2 の更新と、何が違うのか

Windows 11 は年に1回、大型の更新があります。ただ、その中身は年によって大きく違います。

### 25H2・26H2 は「スイッチを入れるだけ」の小さな更新
2025年の 25H2 と、2026年9月末から配信が始まった 26H2 は、24H2 と同じコアOSを使っています。新しい機能はあらかじめ月例の更新で入っており、**小さなファイルをダウンロードして1回再起動するだけ**で新しいバージョンに上がれました。

### 27H2 は「OSの中身ごと入れ替える」更新になる見込み
コアOSを入れ替える更新は、ダウンロードの量も時間も大きくなります。古い周辺機器やソフトとの相性の問題も出やすくなります。

前回コアOSを入れ替えた 24H2 では、配信のあとに次のような不具合が相次ぎました。

- インストール用のメディアで更新したパソコンが、その後の月例の更新を受け取れなくなる
- 約9GBの更新の残りファイルが、ディスクのクリーンアップで消せなくなる

報道によると、今回は互換性の確認に時間をかけるため、テスト版の配布（Windows Insider）を例年より早く始めるとのことです。

## なぜ入れ替えが必要なのか

いま Windows 11 には、**コアOSが2種類あります**。Snapdragon X2 などを積んだ新しいパソコンの一部には、最初から「26H1」という別のコアOSの Windows 11 が入っています。この 26H1 のパソコンは、26H2 には上げられません。Microsoft も「将来のリリースで更新の道を用意する」と説明するにとどめています。

Windows Central によると、27H2 はこの2種類のコアOSを1つにまとめ直し、**すべての Windows 11 のパソコンに向けて配信される**見通しです。そのため、小さな更新では済まず、コアOSの入れ替えになるとみられています。

なお、スタートメニューや検索の反応を速くする改善などは、新しいバージョンを待たずに、すでに月例の更新で配られています。27H2 だけで使える新機能は、今のところ伝えられていません。

## 今のパソコンでやっておきたいこと

27H2 の配信は、早くても約1年後です。今すぐ慌てる必要はありません。ただ、次のことは今のうちから習慣にしておくと安心です。

1. **月例の更新を止めずに入れておく**。26H2 にまだ上がっていない場合は、先に上げておきましょう（[26H2の更新方法](/blog/755512v-d)）
2. **大事なデータは、パソコンとは別の場所にバックアップしておく**。大型の更新の前は特に大切です
3. **大型の更新は、配信が始まってすぐに入れなくてよい**。忙しい時期を避け、数週間ようすを見てからでも間に合います
4. **会社のパソコンは、まず1台で試してから広げる**。業務用のソフトやプリンターが動くかを確かめてから、残りのパソコンを更新します
5. **買い替えは、うわさではなく正式な発表で判断する**。動作要件が変わるかはまだ分かりません。今買うなら、今の要件を満たし、メモリに余裕のあるものを選んでおくと長く使えます（[8GBのパソコンの注意点](/blog/8n4t03f1grhu)）
