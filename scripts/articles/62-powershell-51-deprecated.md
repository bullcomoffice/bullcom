※2026年11月20日時点の Microsoft の発表をもとにしています。

## PowerShell とは

PowerShell は、Windows に最初から入っている、**コマンドでパソコンを操作・自動化するためのツール**です。会社では、次のような作業によく使われています。

- バックアップや、ファイルの整理を決まった時間に自動で行う
- 新しいパソコンの設定（プリンターの追加、ソフトの導入など）をまとめて行う
- ユーザーやパソコンの一覧を作る、ライセンスを管理する

家庭のパソコンで、ふだん意識して使うことはほとんどありません。

## 何が変わるのか

- **PowerShell 5.1 は「非推奨」**になります。セキュリティの修正は続きますが、新しい機能は追加されません
- 5.1 が最初から使える状態で入っているのは、**いまの Windows 11 バージョン 26H2 と Windows Server 2025 が最後**です
- 次の Windows では、5.1 は**必要なときに追加する機能（オンデマンド機能）**になり、将来は使えなくなる予定です
- 代わりに **PowerShell 7** が標準になります

**今日・明日に動かなくなる話ではありません。** ただ、次の Windows への切り替えや、新しいパソコンへの入れ替えのときに、古いスクリプトがそのまま動かないことがあります。

## 自社のスクリプトがどちらで動いているか確かめる方法

### 起動しているプログラムの名前で見る
- **powershell.exe** で動いている → PowerShell 5.1
- **pwsh.exe** で動いている → PowerShell 7 以降

タスク スケジューラに登録された作業の「操作」の欄や、ショートカットの「リンク先」を見ると分かります。

### コマンドで見る
PowerShell の画面で次のように入力します。

- `$PSVersionTable.PSEdition`
  - 「**Desktop**」と出れば PowerShell 5.1
  - 「**Core**」と出れば PowerShell 7 以降

## 準備しておきたいこと

1. **社内で動いているスクリプトを書き出す**：誰が作ったか、何をしているか、どのパソコン・サーバーで動いているか
2. **PowerShell 7 で試す**：5.1 と 7 は1台のパソコンに一緒に入れられます。Microsoft によると、多くのスクリプトはそのまま動きますが、一部の動きが違うため、切り替える前に試すよう呼びかけています
3. **作った人がいない場合は早めに相談する**：前任の方や、昔の業者が作ったスクリプトが動き続けている会社は少なくありません
