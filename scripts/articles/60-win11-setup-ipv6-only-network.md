新しいパソコンの電源を入れて初期設定を進めていたら、Wi-Fi は「接続済み」なのに、次の画面で「インターネット接続が失われました」と出て先へ進めない——。11月、**IPv6 だけのネットワークにつなぐと Windows 11 の初期設定が止まる**という報告が海外で出ました。この記事では、報告の内容と、家庭や会社で初期設定が進まないときの確かめ方を、神戸・明石のパソコン修理店 BULLCOM がまとめました。

※2026年11月20日時点の報道をもとにしています。**Microsoft はこの症状を不具合とも、IPv4 が必要だとも認めていません。**

## 何が報告されたのか

- IPv4 がなく **IPv6 だけがつながるネットワーク**で Windows 11 の初期設定（OOBE）を進めると、ネットワークの画面では「接続済み」と出るのに、次へ進むと「インターネット接続が失われました」となって止まる
- テスト版（Insider）の最新のビルドでも同じ結果だった
- 一般向けに配られている Windows 11 で必ず起きるかは、まだ確かめられていない

## 家庭のパソコンは心配しなくて大丈夫？

**家庭で当たる可能性は低い**と考えられます。

日本の家庭向けの光回線は、IPv6（IPoE）で契約していても、v6プラスや transix などのしくみで **IPv4 の通信も一緒に通す**のが一般的です。そのため、パソコンには IPv4 と IPv6 の両方がつながります。

一方、**会社**では、新しいネットワークへの切り替えにあわせて IPv6 だけのネットワークを使う場面が増えています。社内のネットワークでパソコンを初期設定する場合は注意が必要です。

## なぜ「とばして進む」ができないのか

Windows 11 の初期設定は、Home でも Pro でも、インターネットへの接続と Microsoft アカウントでのサインインが求められます。以前はネットにつながずに進める裏ワザがありましたが、Microsoft はそれを順にふさいできました。Home では、ネットにつながらないと初期設定を終えにくくなっています。

## 初期設定が進まないときの確かめ方

IPv6 に限らず、初期設定で「インターネット接続が失われました」と出る原因はいくつかあります。次の順に確かめてください。

1. **別のネットワークで試す**：スマホのテザリングや、自宅の Wi-Fi など、ふだん使えているネットワークにつなぎ直す。これで進むなら、パソコンではなくネットワーク側が原因です
2. **ルーターを再起動する**：電源を抜いて30秒待ってから入れ直す
3. **有線の LAN ケーブルでつなぐ**：Wi-Fi の相性で止まることもあります
4. **会社のネットワークの場合は、管理している人に確認する**：IPv6 だけのネットワークか、来客用の Wi-Fi のようにログイン画面が出るネットワーク（認証が必要な Wi-Fi）でないか

ログイン画面が出るタイプの Wi-Fi（ホテルや一部の来客用 Wi-Fi）は、初期設定の画面からはログインできず、同じように止まることがあります。

## 会社で何台も初期設定するときは

- 初期設定（キッティング）は、**IPv4 も通るネットワーク**で行う
- 社内のネットワークを IPv6 だけにする計画がある場合は、新しいパソコンの初期設定の手順を先に試しておく
- 年末年始の入れ替えで台数が多い場合は、1台で最後まで通るかを先に確かめてから進める
