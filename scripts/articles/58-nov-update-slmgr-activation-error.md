「11月の Windows Update のあと、ライセンス認証のコマンドが通らなくなった」——会社のパソコンを管理している方から、そんな声が出ています。Microsoft は 11月13日に、この問題を直す臨時の更新（定例外の更新）を出しました。この記事では、何が起きているのか、誰が影響を受けるのか、どう直すのかを、神戸・明石のパソコン修理店 BULLCOM がまとめました。

※2026年11月20日時点の Microsoft の発表をもとにしています。

## 何が起きているのか

2026年11月の Windows のセキュリティ更新を入れた一部のパソコンで、ライセンス認証を操作するツール（SLMGR・slmgr.vbs）のコマンドが、次のエラーで失敗することがあります。

- エラーコード：**0x80041008**（Invalid parameter：パラメーターが正しくありません）

Microsoft によると、主に影響を受けるのは次のような使い方をしている会社です。

- **KMS（キー管理サービス）**でライセンス認証をしている
- slmgr.vbs のコマンドや、自動のしくみ（スクリプトなど）で**プロダクトキーを入れたり、認証の設定を変えたり**している

## 家庭のパソコンは心配しなくて大丈夫？

**ほとんどの場合、心配はいりません。**

- **すでにライセンス認証が済んでいるパソコンは、認証済みのまま**です（Microsoft の説明）
- 家庭のパソコンで slmgr.vbs のコマンドを使う場面は、ふつうありません
- 修正の対象として発表されているのは、Windows 11 バージョン 23H2、Windows 10（22H2 の ESU・Enterprise LTSC）、Windows Server 2019〜2025 です。いまの家庭向けパソコンに多い Windows 11 24H2・25H2・26H2 は、修正の一覧に入っていません

「ライセンス認証が外れた」と表示される場合は、別の原因（部品の交換、ハードウェアの変更など）のこともあります。気になる場合はご相談ください。

## 臨時の更新（定例外の更新）の番号

Microsoft が 11月13日に出した臨時の更新は、Windows のバージョンごとに番号が違います。

| Windows のバージョン | 更新の番号 |
|---|---|
| Windows 11 バージョン 23H2 | KB5136483 |
| Windows 10 バージョン 22H2（ESU）・Windows 10 Enterprise LTSC 2021 | KB5136493 |
| Windows Server 2019・Windows 10 Enterprise LTSC 2019 | KB5136490 |
| Windows Server 2022 | KB5136487 |
| Windows Server 2025 | KB5136489 |

この更新には、11月のセキュリティ更新の中身も含まれています。

## 直し方

### Windows 11 バージョン 23H2 の場合
「設定」→「Windows Update」→「詳細オプション」→「オプションの更新プログラム」から入れられます。Microsoft Update カタログからも入手できます。

### Windows 10・Windows Server の場合
**Windows Update には自動で出てきません。** Microsoft Update カタログから、上の表の番号の更新をダウンロードして入れます。

### 入れたあと
パソコンを再起動してから、失敗していた slmgr.vbs のコマンドをもう一度実行します。

### やってはいけないこと
エラーを消すために、**11月のセキュリティ更新をアンインストールするのはおすすめしません**。その月のセキュリティの修正まで外れてしまいます。臨時の更新を入れて直すのが基本です。

## 会社のパソコンで気をつけたいこと

- **更新は、まず1台で試してから広げる**。キッティング（新しいパソコンの初期設定）や入れ替えの作業がある月は、特に大切です
- **ライセンスの管理を誰が、どの方法でしているか**を一度確かめておく。前任の方が組んだスクリプトが動いている、ということもよくあります
- 2027年1月13日には、Windows Server 2016 と Windows 10 Enterprise LTSC 2021 のサポート（更新の提供）が節目を迎えます。入れ替えの計画もあわせて見直しておくと安心です

## まとめ

- 11月の Windows のセキュリティ更新のあと、一部の会社のパソコンで slmgr.vbs によるライセンス認証の操作がエラー 0x80041008 で失敗することがある
- 主に KMS 認証やスクリプトでライセンスを管理している会社が対象。すでに認証済みのパソコンは認証済みのまま
- Microsoft は 11月13日に臨時の更新を公開。Windows 10・Server は Microsoft Update カタログから入れる
- セキュリティ更新は外さず、臨時の更新を入れて直すのが基本
