Windows 11 の右クリックメニュー、「いつもの項目がない」「その他のオプションを確認」を押さないと出てこない、と不便に感じていた方は多いと思います。**11月の Windows の更新で、右クリックメニューを自分好みに変えられるように**なりました。あわせて、パソコンを入れ直す新しい機能も加わっています。この記事では、11月の更新で変わったことを、神戸・明石のパソコン修理店 BULLCOM がまとめました。

※2026年11月20日時点の報道をもとにしています。新しい機能は**順番に配られている**ため、まだ出ていないパソコンもあります。

## 右クリックメニューを変える方法

### できるようになったこと
- 「送る」「印刷」「ショートカットの作成」「パスのコピー」「画像の回転」などの項目を、**表示する・しないを1つずつ切り替え**られる
- アプリごとに、メニューの最初の画面に出すか、サブメニューに入れるかを選べる
- 昔のメニュー（その他のオプション）を使うかどうかも設定できる

### 設定のしかた
1. エクスプローラーでファイルやフォルダーを**右クリック**する
2. 「**メニューのカスタマイズ**」を選ぶ
3. 出したい項目をオン、いらない項目をオフにする

「設定」→「個人用設定」→「コンテキストメニュー」からも同じ画面を開けます。

「メニューのカスタマイズ」が出てこない場合は、まだそのパソコンに配られていないか、11月の更新が入っていません。

## 11月の更新が入っているか確かめる

1. 「設定」→「Windows Update」を開く
2. 「2026-11 Security Update（KB5132061）」が「再起動が必要」になっていたら、パソコンを再起動する
3. 何も出ていなければ「更新プログラムのチェック」を押す

なお、**Windows 11 バージョン 24H2 の Home・Pro は 10月で更新の提供が終わりました。** まだ 24H2 の場合は、26H2 に上げておきましょう（[26H2の更新方法](/blog/755512v-d)）。

## 新しい「PCの再構築（クラウド リビルド）」の注意点

11月の更新では、**インターネット経由で Windows 11 を入れ直せる「PCの再構築」**という機能も、順番に配られ始めました。Windows が起動しなくなり、手元に回復用の USB メモリがない場合でも、入れ直しができるというものです。

便利な機能ですが、**パソコンの中のファイルは残りません。** 写真や書類も消えてしまいます。

> Windows が起動しなくなったときは、**入れ直す前に、データを取り出せないかを先に考えてください。** 「自動修復を準備しています」のあとに「デバイスで問題が発生したため、修復できませんでした」と出て起動しないパソコンは、データをそのままに直せることが多いです（[起動しないパソコンの修理](/boot-repair)）。

## ほかに変わったこと

- エクスプローラーの検索結果で、ファイル名・場所・更新日時が見やすくなった
- 「スマートフォン連携」で、届いたメッセージにカーソルを合わせると中身をのぞけるようになった
- セキュリティの修正も多数（11月の更新は、必ず入れておきたい更新です）
