「急に日本語が打てなくなった」「変換キーを押しても反応しない」——業務が完全に止まるため、緊急度の高いご相談です。神戸・明石のBULLCOMでもよく承ります。**多くはキーの押し間違いか、IME（日本語入力システム）の一時的な不調**で、順に試せば数分で戻ります。

## まず試す：キー操作で切り替える

意外なほど多いのが、単純な切り替えミスです。

- **半角/全角キー**を押す（キーボード左上、`1`の左）
- **Alt + 半角/全角**
- **Windowsキー + スペース**（入力方式の切り替え）
- **Ctrl + Shift**（キーボードレイアウトの切り替え）

3つ目・4つ目は、他のキーと一緒に押してしまい**意図せず英語入力に切り替わっている**ことがあります。まずここを疑ってください。

画面右下の通知領域に「**あ**」「**A**」の表示があります。「A」になっていれば英数入力の状態です。ここをクリックしても切り替えられます。

## 症状別の対処

### 症状①：文字が入力できない、反応しない

1. 一度**別のアプリ**（メモ帳など）で試す
   - メモ帳では打てる → **元のアプリの問題**
   - どこでも打てない → IME側の問題
2. **IMEを再起動する**
   - Ctrl + Shift + Esc でタスクマネージャー
   - 「Microsoft IME」を探して「タスクの終了」
   - 自動で再起動します
3. パソコンを再起動する

### 症状②：変換が異常に遅い、候補が出ない

学習データが壊れている可能性があります。

**設定 → 時刻と言語 → 言語と地域 → 日本語の「…」→ 言語のオプション → Microsoft IME の「…」→ キーボードオプション → 学習と辞書 → 「入力履歴の消去」**

学習内容はリセットされますが、動作は正常化します。

### 症状③：勝手に半角英数になる

アプリごとに入力モードを記憶する設定が影響していることがあります。

同じ画面の「全般」から、**「以前のバージョンのMicrosoft IMEを使う」**を有効にすると解決するケースがあります。新しいIMEとアプリの相性問題は実際に報告されています。

### 症状④：記号の位置がおかしい（@が打てない等）

**キーボードのレイアウトが英語配列（US）になっています。**

- `@` を押すと `"` が出る
- `_`（アンダースコア）が打てない

これはIMEではなくキーボードの認識の問題です。

**設定 → 時刻と言語 → 言語と地域 → 日本語 → 「…」→ 言語のオプション → キーボードレイアウト → 「レイアウトを変更する」→「日本語キーボード（106/109キー）」**

変更後、再起動が必要です。

## 予測変換・入力履歴が邪魔な場合

「以前打った内容が候補に出て困る」というご相談もあります。とくに**人前で画面を見せる機会がある方**は注意が必要です。

- 学習と辞書 →「**入力履歴を使用する**」をオフ
- 既に溜まった履歴は「入力履歴の消去」で削除

## それでも直らない場合

IME自体を入れ直します。

**設定 → アプリ → インストールされているアプリ → Microsoft IME → 詳細オプション →「リセット」**

これで初期状態に戻ります。ユーザー辞書に登録した単語も消えるため、大切な登録がある場合は事前にエクスポートしておいてください。

## キーボードの故障の可能性

次の場合は、IMEではなくキーボードの物理的な問題です。

- **特定のキーだけ効かない**
- 押していないのに文字が入り続ける
- 飲み物をこぼした後から症状が出た

とくに液体をこぼした場合は、**すぐに電源を切って乾かしてください。**通電したままだと基板まで損傷が及びます。外付けキーボードを繋いで正常に打てるなら、本体キーボードの故障と判断できます。

## まとめ

まず**半角/全角キー**と**Windowsキー + スペース**を試してください。画面右下が「A」になっていないかも確認します。これで戻ることが大半です。

直らない場合はIMEの再起動 → 入力履歴の消去 → IMEのリセット、の順で。**特定のキーだけ効かない場合は物理的な故障**なので、修理をご検討ください。
