「Windows 11にしようとしたら『TPM 2.0が必要です』と表示された」——神戸・明石のBULLCOMにも、この画面のスクリーンショットを持ってご相談に来られる方が増えています。**実は搭載されているのに、設定で無効になっているだけというケースが少なくありません。**確認手順と、有効化の方法をご案内します。

## TPM 2.0とは何か

暗号化やセキュリティ情報を安全に保管するための小さなチップです。パスワードや暗号鍵を、他のソフトから読み取られない場所に隔離して保存します。

Windows 11ではこれが必須要件になりました。**性能とは無関係**なので、「まだ十分速いのに弾かれる」という現象が起きます。

## 手順①：搭載されているか調べる

まず、そもそも載っているかを確認します。

1. キーボードの **Windowsキー + R** を同時に押す
2. `tpm.msc` と入力して Enter
3. 「コンピューターのTPMの管理」という画面が開きます

表示される内容で状況が分かります。

| 表示 | 意味 |
|---|---|
| 「TPMは使用する準備ができています」 | **有効**。ここは問題なし |
| 「互換性のあるTPMが見つかりません」 | 未搭載、または**BIOSで無効になっている** |
| 仕様バージョン **2.0** | Windows 11の要件を満たす |
| 仕様バージョン **1.2** | 要件を満たさない |

「見つかりません」と出ても、まだ諦めないでください。**BIOSで無効にされているだけ**のことがよくあります。

## 手順②：BIOSで有効化する

2016年以降の機種なら、搭載されているのに無効設定になっているケースが相当あります。

1. パソコンの電源を切る
2. 電源を入れた直後に **F2 / F10 / Delete** のいずれかを連打（機種により異なります）
3. BIOS/UEFI設定画面が開く
4. 「Security」「Advanced」といった項目を探す
5. 次のような名称の項目を **Enabled** に変更する

メーカーによって呼び名が違うのが厄介な点です。

- **Intel PTT**（Intel Platform Trust Technology）
- **AMD fTPM**（AMD製CPUの場合）
- **TPM Device** / **Security Device Support**

6. 保存して終了（多くはF10）

再起動後、もう一度 `tpm.msc` で確認してください。「準備ができています」に変われば成功です。

## 手順③：総合的に判定する

TPM以外の要件も含めてまとめて確認したい場合は、Microsoft公式の「PC正常性チェック」アプリが使えます。何が原因で弾かれているかを一覧で示してくれます。

TPMをクリアしても、**CPUの世代**で弾かれることがあります。Intel第8世代（2017年以降）が目安で、これより古いと基本的に対象外です。

## BIOS操作に不安がある方へ

BIOSは設定を誤ると起動しなくなることがある領域です。次に当てはまる場合は、無理に進めないことをおすすめします。

- どのキーでBIOSに入るか分からない
- 英語の画面ばかりで、どれが該当項目か判断できない
- 項目名がここで挙げたどれとも一致しない

**持ち込み診断は無料**ですので、判定だけのご来店でも構いません。「上げられるのか、買い替えなのか」をはっきりさせるだけでも、その後の判断が楽になります。

## 有効化する前にやっておくこと

TPMを有効化すると、既に暗号化されているドライブが開けなくなることが稀にあります。念のため次を確認してください。

- **BitLockerを使っている場合は回復キーを控えておく**
- 大事なデータのバックアップを取っておく

企業から貸与されたパソコンの場合、BitLockerが有効になっていることが多いので特に注意が必要です。
