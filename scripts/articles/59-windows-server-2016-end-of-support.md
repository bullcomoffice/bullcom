「事務所のサーバー、いつ入れたものか分からない」——そんな会社は少なくありません。**Windows Server 2016 は、2027年1月にサポートが終わります。** Microsoft は 11月13日に「あと60日」の注意喚起を出しました。年末年始をはさむので、実際に動ける日はもっと少なくなります。この記事では、サポート終了で何が変わるのか、自社のサーバーをどう確かめるか、いまからできることを、神戸・明石のパソコン修理店 BULLCOM がまとめました。

※2026年11月20日時点の Microsoft の発表をもとにしています。

## いつ、何が終わるのか

- **2027年1月13日**（Microsoft の告知の日付）に、**Windows Server 2016 のすべてのエディションの延長サポートが終わります**
- **2027年1月の月例の更新が、最後のセキュリティ更新**になります
- 小規模の会社で使われてきた **Windows Server 2016 Essentials の機能（リモート Web アクセスなど）のサポートも同じ日に終わります**

サポートが終わっても、サーバーが急に止まるわけではありません。ただ、**新しく見つかった弱点（脆弱性）が直されないまま**になります。ファイルの共有や社内のシステムを置いているサーバーが攻撃の入り口になると、会社のデータ全体に影響が出ます。

## 自社のサーバーが 2016 か確かめる方法

1. サーバーにサインインする
2. キーボードの **Windows キー＋R** を押し、「**winver**」と入力して Enter
3. 表示された画面で「Windows Server 2016」と書かれていれば対象です

「サーバーにサインインする方法が分からない」「どこにあるのかも分からない」という場合も、珍しくありません。導入した業者や前任の方に確認するか、ご相談ください。

### こんなものも「サーバー」です
- 事務所の奥に置いてある、ファイル共有用のパソコンのような機械
- 会計・販売管理などの業務ソフトが入っている機械
- 複合機のスキャンの保存先や、バックアップの保存先になっている機械

## いまからできること

### 1. 使い道を書き出す
そのサーバーで何をしているか（ファイル共有、業務ソフト、バックアップの保存先など）を書き出します。入れ替え先を決めるのに必要です。

### 2. 入れ替え先を決める
主な選択肢は次の3つです。

| 入れ替え先 | 向いている会社 |
|---|---|
| 新しいサーバー（Windows Server 2025） | 業務ソフトがサーバーでしか動かない、台数が多い |
| クラウドのファイル共有（OneDrive・SharePoint など） | 主な使い道がファイルの共有だけ |
| NAS（ネットワークにつなぐ保存装置） | 少人数で、ファイルの共有とバックアップが中心 |

業務ソフトを使っている場合は、**新しい Windows Server に対応しているかを、ソフトの会社に先に確認**してください。

### 3. どうしても間に合わない場合
Microsoft は、サポート終了後も最大3年間セキュリティ更新を受けられる **ESU（拡張セキュリティ更新プログラム）** を用意しています。ただし、ボリュームライセンスとソフトウェアアシュアランスの契約などが条件で、**Standard・Datacenter エディションが対象**です。Essentials を使っている小規模の会社は、入れ替えを前提に考えるのが現実的です。

## 年末年始をはさむので早めの準備を

- 1月13日までの約50日のうち、年末年始の休みが入ります
- 新しい機械の手配、データの移し替え、業務ソフトの入れ直しには、思ったより日数がかかります
- 入れ替えのあとも、しばらくは古いサーバーを**ネットワークから切り離して**保管しておくと、取り出し忘れたデータがあっても安心です

同じ 2027年1月13日には、工場の機械や受付端末などで使われる **Windows 10 Enterprise LTSC 2021** も、通常のサポート（月例の更新の提供）が終わります。あわせて確認しておきましょう。
