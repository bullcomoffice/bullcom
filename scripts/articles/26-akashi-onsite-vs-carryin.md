「持ち込んだ方が安いのは分かるけれど、自分の症状だとどちらがいいのか分からない」——明石市のお客様からよくいただくご質問です。**症状によって、向いている方法ははっきり分かれます。**明石市に隣接する神戸市西区伊川谷のBULLCOMが、判断の基準をご案内します。

## まず結論：症状で選ぶのが正解

| こんな症状・ご要望 | 向いている方法 |
|---|---|
| 起動しない・電源が入らない | **持ち込み**（時間をかけて診断する必要がある） |
| 動作が遅い・異音がする | **持ち込み**（部品交換を伴うことが多い） |
| ネットに繋がらない・Wi-Fiが不安定 | **出張**（現地の回線・機器を見ないと分からない） |
| プリンターが繋がらない | **出張**（プリンター本体と設置環境の確認が必要） |
| 新しいパソコンの設定をしてほしい | **出張**（周辺機器やネット環境ごと整えられる） |
| デスクトップで持ち運びが大変 | **出張** |
| 平日に時間が取れない | **郵送** |

**「パソコン単体の問題」なら持ち込み、「環境が関わる問題」なら出張**——これが基本の考え方です。

## 持ち込み修理のメリットと注意点

### メリット
- **診断料が無料**（修理をされない場合も費用はかかりません）
- 出張費がかからないぶん、総額を抑えられる
- 時間をかけた検証ができるため、原因の切り分けが正確

### 注意点
- 店舗までお持ちいただく必要がある
- お預かりになる場合、その間パソコンが使えない

明石市からのアクセスについては、店舗が**明石市との市境（神戸市西区伊川谷町有瀬）**にあります。朝霧・大蔵谷方面からはすぐ、明石駅周辺・大久保・魚住方面からもお車でお越しいただける距離です。

## 出張修理のメリットと注意点

### メリット
- ご自宅・オフィスまで伺うので、運ぶ必要がない
- **設置環境ごと確認できる**（ネット回線・ルーター・プリンターなど）
- 作業内容をその場で見ていただける

### 注意点
- 出張費がかかる（明石市は**出張エリアA・¥5,500**）
- その場で直せない症状の場合、お預かりになることがある

なお明石市は市内全域が出張エリアAですので、**二見町・魚住町など市西部でも出張費は変わりません。**

## 郵送修理という第三の選択肢

お仕事などでご来店の時間が取りにくい方には、郵送もご利用いただけます。

1. お電話またはLINEで事前にご予約
2. パソコンを梱包して発送（梱包は丁寧にお願いします）
3. お見積り後、ご了承いただいてから作業
4. 修理完了後にご返送（**返送料は当社負担**）

自信がない場合は、ヤマト運輸のパソコン宅急便などをご利用いただくと安心です。

## 判断に迷ったら電話で聞いてください

実際のところ、**症状を聞けばどちらが良いかはその場でお答えできます。**

お電話（078-912-2656／9:00〜19:00）の際に、次の3点をお伝えいただけるとスムーズです。

「持ち込みで大丈夫ですよ」「それは現地を見ないと分かりませんね」と、その場で判断してご案内します。
