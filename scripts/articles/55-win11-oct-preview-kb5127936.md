2026年10月28日、Windows 11 の「プレビュー更新プログラム」が配信されました。エクスプローラーの右クリックメニューが新しくなるほか、Windowsが起動しなくても入れ直せる「クラウド再構築」など、大きめの変更が含まれています。この記事では、何が変わるのか、すぐに入れたほうがよいのかを、パソコン修理の現場の目線でまとめました。

※2026年10月30日時点の情報です。

## 何が配信されたのか

- **対象**: Windows 11 の 25H2・26H2（更新プログラム KB5127936。ビルド 26200.9818／26300.9818）
- **種類**: **任意（オプション）のプレビュー更新**です。自分で「ダウンロードしてインストール」を押さない限り、自動では入りません
- **セキュリティの修正は含まれていません**（セキュリティの修正は 10月14日の月例更新で配信済み）
- 今回の変更は、**11月11日（日本時間）の月例更新で、すべてのパソコンに配信される予定**です

新機能の多くは「段階的な配信」で、更新を入れてもすぐには表示されないことがあります。

## 主な新機能（家庭・小さな会社に関係するもの）

### エクスプローラーの右クリックメニューが新しくなる
右クリックしたときのメニューが作り直され、どの項目を表示するかを自分で選べるようになります。検索結果の見た目も分かりやすくなります。

### 「クラウド再構築」で、起動しなくてもWindowsを入れ直せる
Windows Update からWindowsとドライバーを取り寄せて入れ直す機能です。**USBメモリなどの準備がなくても、Windowsが起動しない状態から入れ直せる**のが特徴です。
ただし、入れ直す前にドライブを消去する選択肢もあり、**消去したデータは元に戻せません**。大切なデータがあるパソコンでは、使う前にバックアップを取るか、ご相談ください。

### そのほか
- **拡大鏡**: モニターごとに拡大率を変えられる、まぶしさを抑えるコントラストの切り替えができる
- **プライバシーとセキュリティ**: カメラ・マイク・位置情報の設定がまとまり、どのアプリが使ったかが見やすくなる
- **回復環境でのWi-Fi**: トラブル時に使う回復環境が、保存済みのWi-Fiに自動でつながる
- **新しいパソコンへの引っ越し**: バックアップから設定を戻したあと、何が戻ったかの一覧が表示される
- **ノートパソコンの休止状態**: 電池が80%以上のときは休止状態に入りにくく、10%を切ると早めに休止状態に入る

## 主な不具合の修正

- **リモートデスクトップ**: 「管理者保護」が有効なパソコンに、管理者でない利用者が接続するとエラー 0xC000000D で失敗する問題を修正（[10月17日の記事](/blog/7b5vr5spoq)で取り上げた不具合です）
- **スマートアプリコントロール**: 一度オフにすると、オンに戻す設定が灰色で押せなくなる問題を修正
- **会社のVPN（Always On VPN）**: 「接続中」のまま止まる問題を修正
- **AMDのグラフィックス**: 一部の機種で、HDMI・DisplayPort から音が出ない問題を修正

## 気をつけたい既知の不具合

Microsoftは、**古い規格のUSBオーディオ機器（USB Audio Class 1.0）**で、機器が認識されない（コード10）、音が出ない、音量を変えられないことがあると公表しています。9月8日の更新から続いている問題で、修正の時期はまだ示されていません。
USB接続のスピーカーやヘッドセット、オーディオインターフェースを使っている方は、困っていなければ今回のプレビュー更新は見送るのが無難です。

## 入れるべき？ 判断の目安

| こんな方 | おすすめ |
|---|---|
| 特に困っていない | **入れずに待つ**（11月11日の月例更新で自動的に入ります） |
| リモートデスクトップ・VPN・AMDの音の不具合で困っている | 入れると直る可能性がある |
| USBオーディオ機器を使っている | 見送る |
| 会社のパソコン | 自分で入れず、社内の管理者に確認する |

入れる場合は、「設定」→「Windows Update」→「更新プログラムのチェック」を押し、表示された KB5127936 の「ダウンロードしてインストール」を選びます。念のため、入れる前に大切なデータのバックアップを取っておきましょう。
Windows 11 のバージョンの確認や更新の進め方は、[「Windows 11 26H2の配信が開始」](/blog/755512v-d)もご覧ください。

- 10月28日に Windows 11 の任意のプレビュー更新（KB5127936）が配信された。セキュリティの修正は含まれていない
