「実家の親がパソコンを使いづらそうにしている」「文字が小さくて読めないと言われる」——神戸・明石のBULLCOMにも、離れて暮らすご家族からのご相談が寄せられます。**Windowsには標準で、見やすさ・使いやすさを調整する機能が揃っています。**追加のソフトを買う必要はありません。実際に効果の大きい設定を順にご案内します。

## ① 全体を大きくする（最も効果的）

文字だけでなく、アイコンやボタンごと大きくする設定です。**これが一番効きます。**

**設定 → システム → ディスプレイ → 拡大縮小**

- 125% または 150% に変更
- 変更後、一度サインアウトすると全体に反映されます

「文字サイズだけ」を変えるより、ボタンも大きくなるため**クリックしやすさが段違いに変わります。**手元が不安定な方には特に有効です。

## ② 文字だけをさらに大きく

拡大縮小で全体を大きくしても文字が読みにくい場合は、追加で調整します。

**設定 → アクセシビリティ → テキストのサイズ**

スライダーを動かすと、プレビューを見ながら調整できます。

## ③ マウスポインターを見やすくする

「カーソルがどこにあるか分からない」というお困りごとは非常に多いです。

**設定 → アクセシビリティ → マウスポインターとタッチ**

- **サイズ**を大きくする
- **色**を変更する（黒や反転色にすると背景で見失いません）

あわせて、**Ctrlキーを押すとポインターの位置が表示される**設定も便利です。

**コントロールパネル → マウス → ポインターオプション →「Ctrlキーを押すとポインターの位置を表示する」**

## ④ ダブルクリックの速度を遅くする

「ダブルクリックがうまくできない」という原因の多くは、既定の速度が速すぎることです。

**コントロールパネル → マウス → ボタン → ダブルクリックの速度**

スライダーを**遅い方**へ動かしてください。これだけで操作が格段に楽になる方がいます。

## ⑤ デスクトップを整理する

見やすさは「情報を減らすこと」でも向上します。

- **よく使うものだけをデスクトップに残す**（5個以内が目安）
- アイコンを大きく表示（デスクトップで右クリック → 表示 → 大アイコン）
- 使わないアイコンはフォルダにまとめる

**スタートメニューにピン留め**しておくのも有効です。よく使うアプリだけを並べておけば、探す手間がなくなります。

## ⑥ 目に優しい表示にする

**設定 → システム → ディスプレイ → 夜間モード**

画面の青みを抑え、目の疲れを軽減します。時間指定で自動的に切り替わるよう設定できます。

コントラストを上げたい場合は、**設定 → アクセシビリティ → コントラストテーマ**も試してみてください。

## ⑦ 音声で読み上げる

文字を読むのが負担な場合、読み上げ機能が使えます。

**設定 → アクセシビリティ → ナレーター**

慣れが必要な機能ですが、視力に不安がある方には有効な選択肢です。

## 設定以外で効果があること

技術的な設定と同じくらい、次のことが効きます。

- **手順を紙に書いて貼っておく**（「メールを見る方法」など、1枚1つの操作）
- ショートカットの名前を分かりやすく変える（「インターネット」「写真」など）
- 使わない機能は**思い切って消す**（選択肢が減ると迷いません）
- **遠隔サポートの設定をしておく**（離れていても画面を見ながら教えられます）

とくに最後の項目は、離れて暮らすご家族には非常に有効です。電話で「その画面の右上の…」と説明するより、実際に画面を見た方が早く解決します。

## 安全面もあわせて確認を

高齢の方は、サポート詐欺の被害に遭いやすい傾向があります。この機会に次も確認しておいてください。

- Windows Updateが適用されているか
- ウイルス対策が有効か
- **「画面に電話番号が出ても絶対にかけない」**と伝えておく

最後の一言を伝えておくだけで、被害の多くは防げます。

## BULLCOMのサポート

- 見やすさ・使いやすさに合わせた設定作業
- ご高齢の方向けの初期設定、デスクトップ整理
- 遠隔サポートの設定
- セキュリティ点検（**持ち込み診断は無料**）
- 神戸市・明石市へ出張対応（出張エリアA・¥5,500〜）

**ご本人のお使いの様子を見ながら設定できる出張が最も効果的**です。「何が使いにくいのか本人もうまく説明できない」という場合こそ、現地で拝見すると原因がはっきりします。[神戸市](/area/kobe)・[明石市](/area/akashi)へ伺います。

## まとめ

最も効果があるのは、**文字サイズではなく「拡大縮小」を125〜150%にする**ことです。ボタンごと大きくなり、クリックのしやすさが変わります。

あわせて**マウスポインターの拡大**と**ダブルクリック速度を遅く**する。この3点だけでも、使いやすさは大きく改善します。設定作業でお困りの際は、出張でも承りますのでご相談ください。
