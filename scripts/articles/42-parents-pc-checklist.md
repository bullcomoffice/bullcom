年末年始の帰省は、実家のパソコンを点検する数少ない機会です。「電話では何が起きているか分からない」「毎回同じことを聞かれる」——神戸・明石のBULLCOMにも、帰省後のご相談が毎年増えます。**限られた滞在時間で効率よく確認できるよう、優先順にまとめました。**

## 最優先の3項目（15分で終わります）

時間がなくても、この3つだけは確認してください。

### ① Windows Updateが適用されているか

**設定 → Windows Update**

更新が何か月も止まっているケースは珍しくありません。「更新の通知が出るけど、よく分からないので放置していた」——非常によくあります。

**その場で適用してください。**再起動に時間がかかるので、他の作業と並行して進めるのがおすすめです。

なお、**Windows 10のパソコンはサポートが終了しています。**まだWindows 10なら、この機会に対処を検討してください。

### ② ウイルス対策が有効か

**設定 → プライバシーとセキュリティ → Windowsセキュリティ**

- Windows標準の「Microsoft Defender」が有効ならまず問題ありません
- **期限切れの市販ソフトが入っていると、かえって危険です**（Defenderが無効化されたまま、市販ソフトも機能していない状態）

期限切れのソフトを見つけたら、アンインストールしてDefenderを有効に戻してください。

### ③ バックアップが取られているか

写真や書類が失われると取り返しがつきません。

- 外付けHDDやUSBメモリにコピーがあるか
- なければ、**この機会に外付けHDDを買って設定してあげる**

とくにご高齢の方の場合、思い出の写真がパソコンの中だけにあることが多いです。**故障してから相談を受けても手遅れ**なので、ここは強くおすすめします。

## 詐欺・トラブルの予防（最重要の会話）

技術的な設定より、実はこれが一番効きます。

### 伝えておくべきこと

> **「画面に電話番号が出ても、絶対にかけないで」**

サポート詐欺の被害は、この一言で大半が防げます。「ウイルスに感染しました」という警告画面が出て、表示された番号に電話をかけてしまう——これが典型的な手口です。

あわせて伝えてください。

- **警告音が鳴っても、まずは電源ボタンの長押しで消してよい**
- **お金を払う前に必ず自分（家族）に連絡する**
- 「今すぐ」「至急」と急かすものは全部疑ってよい

### メール・SMSについて
- 銀行や宅配業者を装ったメールが届くことを説明しておく
- **リンクを踏む前に一度相談する**習慣をつけてもらう

## 使いやすさの改善

「使いづらい」と言われている場合、次を試してください。

### 画面を大きくする
**設定 → システム → ディスプレイ → 拡大縮小** を 125% か 150% に。

文字だけでなく**ボタンごと大きくなる**ので、クリックしやすさが変わります。効果が最も大きい設定です。

### マウスポインターを見やすく
**設定 → アクセシビリティ → マウスポインターとタッチ** でサイズと色を変更。

### ダブルクリックの速度を遅く
**コントロールパネル → マウス → ボタン**。「ダブルクリックができない」の原因はたいてい速度設定です。

### デスクトップを整理
よく使うものだけを残し、あとはフォルダにまとめる。**アイコンが5個以内**だと迷いません。

## パフォーマンスの確認

### 動作が重いと言われたら
Ctrl + Shift + Esc でタスクマネージャーを開き、**パフォーマンス タブ → ディスク** を確認。

**「HDD」と表示されていれば、SSD換装で劇的に改善します。**買い替えを検討する前に、この選択肢を伝えてあげてください。費用も本体購入よりはるかに抑えられます。

### 空き容量
Cドライブの空きが10%を切っていたら、不要ファイルを整理してください。

## 帰省後のために

滞在中にやっておくと、後々ラクになります。

- **遠隔サポートの設定**（離れていても画面を見ながら教えられます）
- Wi-Fiのパスワードを控えておく
- **パソコンの型番を写真に撮っておく**（電話相談時に役立ちます）
- よく使う操作を紙に書いて貼っておく
- 近所の修理店の連絡先をメモして渡しておく

**遠隔サポートの設定**は特に有効です。電話で「その画面の右上の…」と説明するのは双方にとって負担が大きく、実際に画面を見られるだけで解決までの時間がまったく変わります。

## まとめ

時間がなければ、**Windows Update・ウイルス対策・バックアップ**の3つだけ確認してください。15分で済みます。

そして技術的な作業より効くのが、**「画面に電話番号が出ても絶対にかけない」**と伝えておくこと。この一言でサポート詐欺の被害は大きく防げます。

使いづらさを訴えられたら、**拡大縮小を125〜150%に**。動作が重いなら、**ディスクがHDDかどうか**を確認してみてください。
