「更新プログラムを構成しています 90%」から何時間も動かない——パソコンのトラブルの中でも、とりわけ不安になる場面です。神戸・明石のBULLCOMにも、この状態でのお電話が定期的にかかってきます。**まず知っておいてほしいのは、待つべき時間の目安**です。焦って電源を切ると、事態が悪化します。

## まず：どれくらい待つべきか

**大型更新の場合、90%の表示で1〜2時間止まって見えることは正常の範囲内です。**

判断の目安は次のとおりです。

| 状況 | 判断 |
|---|---|
| HDDのアクセスランプが点滅している | **動いています。待つ** |
| ファンが回っている、本体が温かい | 処理中の可能性が高い。待つ |
| **4時間以上、まったく変化がない** | 固まっている可能性 |
| ランプが完全に消灯、冷たい | 停止している可能性 |

**アクセスランプの点滅が最良の判断材料**です。点滅していれば内部で処理が続いています。少なくとも**3〜4時間は待つ**ことをおすすめします。

## 固まっている場合の対処

4時間以上変化がなく、ランプも動かない場合の手順です。

1. **電源ボタンを10秒長押し**して強制終了
2. 30秒ほど待つ
3. 電源を入れる

多くの場合、Windowsが自動で更新をロールバック（元に戻す）し、起動します。「以前のバージョンのWindowsを復元しています」と表示されたら、そのまま待ってください。

**この操作にはリスクがあります。**運悪く重要な書き込み中だった場合、起動しなくなることがあります。だからこそ、先に十分待つことが大切です。

## 更新が繰り返し失敗する場合

同じ更新が何度も失敗する場合は、次を順に試します。

### ① トラブルシューティングツールを使う
**設定 → システム → トラブルシューティング → その他のトラブルシューティング → Windows Update →「実行する」**

Windows標準の自動修復です。まずこれで直ることがあります。

### ② 空き容量を確保する
更新には**20GB以上の空き**が必要なことがあります。ディスクの空きが少ないと失敗します。

- 「設定 → システム → ストレージ」で空き容量を確認
- 不要なファイル、古い更新ファイルを削除

### ③ 更新キャッシュをリセットする
ダウンロード済みのファイルが壊れている場合の対処です。スタートを右クリック →「ターミナル（管理者）」で、次を順に実行します。

```
net stop wuauserv
net stop bits
```

その後、エクスプローラーで `C:\Windows\SoftwareDistribution\Download` の中身を削除し、

```
net start wuauserv
net start bits
```

で戻します。この操作は安全で、失敗した更新ファイルを捨てて再取得させるものです。

### ④ システムファイルを修復する
```
sfc /scannow
DISM /Online /Cleanup-Image /RestoreHealth
```

どちらも時間がかかりますが、途中で閉じないでください。

## 更新前にやっておくべきこと

トラブルを避けるための予防策です。

- **大事なデータのバックアップ**（更新前は特に）
- 十分な空き容量の確保
- **ノートPCはACアダプタを接続**（バッテリー切れが最悪の事態を招きます）
- 時間に余裕があるときに実施する（**外出直前は避ける**）
- 外付け機器を外しておく

## 更新のタイミングを自分で決める

「勝手に再起動される」を防ぐには、アクティブ時間の設定が有効です。

**設定 → Windows Update → 詳細オプション → アクティブ時間**

この時間帯には自動再起動されなくなります。仕事で使う時間帯を指定しておいてください。

**一時停止**（最大5週間）も可能ですが、セキュリティ更新が止まるため長期の停止はおすすめしません。

## それでも直らない場合

次の状態なら、ご自身での対応は難しい段階です。

- 更新と復元を延々と繰り返す
- 「スタートアップ修復」から進まない
- **青い画面が繰り返し出る**
- 更新後、起動しなくなった

**データが取り出せる状態のうちにご相談ください。**繰り返しの強制終了はストレージに負担をかけ、状況を悪化させます。

## BULLCOMのサポート

- 更新の停止・失敗からの復旧（**持ち込み診断は無料**）
- 起動しなくなったPCからのデータ救出
- ストレージ交換・システムの再構築
- Windows 11への移行相談
- 神戸市・明石市へ出張対応（出張エリアA・¥5,500〜）

「もう何時間も止まっている」という段階でお電話いただければ、待つべきか切るべきかの判断もお伝えできます。[神戸市](/area/kobe)・[明石市](/area/akashi)へ出張も承ります。

## まとめ

まず**アクセスランプを見てください。**点滅していれば動いています。**3〜4時間は待つ**のが基本です。

固まっている場合は電源ボタン10秒長押しで強制終了し、自動修復に任せます。繰り返し失敗する場合は、トラブルシューティング → 空き容量確保 → キャッシュのリセット、の順で。起動しなくなったら、無理をせずご相談ください。
