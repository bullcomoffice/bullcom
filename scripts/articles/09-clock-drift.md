「電源を入れるたびに時刻が狂っている」「日付が2000年になっていた」——地味ですが、放っておくと実害が出るトラブルです。神戸・明石のBULLCOMでも、古めのパソコンで定期的にご相談を受けます。**毎回リセットされるなら、内部の電池切れがほぼ確実**です。原因の見分け方と対処をご案内します。

## 時刻がずれると何が困るのか

「数分ずれるくらい」と軽く見られがちですが、実際には次のような影響が出ます。

- **Webサイトが開けなくなる**（証明書の有効期限判定に失敗するため）
- ネットバンキング・通販サイトにログインできない
- メールの送受信でエラーが出る
- ファイルの更新日時が滅茶苦茶になり、どれが最新か分からなくなる
- Windows Updateが失敗する

「急にどのサイトも見られなくなった」というご相談の原因が、実は時計のずれだったというケースは珍しくありません。

## まず切り分け：ずれ方で原因が分かる

| ずれ方 | 疑われる原因 |
|---|---|
| **電源を切るたびにリセットされる**（2000年等に戻る） | **CMOS電池の寿命**（ほぼ確定） |
| 少しずつ数分〜数十分ずれていく | 時刻同期の設定 |
| 9時間ちょうどずれている | **タイムゾーンの設定ミス** |
| 1時間ずれている | 夏時間の設定 |

**9時間ぴったりのずれ**は非常に多いパターンです。日本標準時と協定世界時（UTC）の差がそのまま出ている状態で、設定を直すだけで解決します。

## 対処①：タイムゾーンと自動同期の設定

まずここを確認します。

**設定 → 時刻と言語 → 日付と時刻**

- 「タイムゾーンを自動的に設定する」→ **オン**
- タイムゾーンが「**(UTC+09:00) 大阪、札幌、東京**」になっているか
- 「時刻を自動的に設定する」→ **オン**
- 「今すぐ同期」ボタンを押す

「今すぐ同期」で正しい時刻になれば、この時点で解決です。

## 対処②：時刻同期がうまくいかない場合

同期に失敗する場合は、同期先のサーバーを変更してみます。

1. コントロールパネル →「日付と時刻」
2. 「インターネット時刻」タブ →「設定の変更」
3. サーバーを **ntp.nict.jp** に変更（日本の標準時サーバー）
4. 「今すぐ更新」

`time.windows.com` は混雑して同期に失敗することがあるため、国内サーバーの方が安定します。

## 対処③：毎回リセットされるならCMOS電池

**電源を切るたびに時刻が初期化される場合、内部のボタン電池（CR2032）が切れています。**

パソコンには、電源を抜いても時計と基本設定を保持するための小さな電池が載っています。これが寿命を迎えると、電源を切った瞬間に記憶が飛びます。

- 寿命の目安は**5〜10年**
- 症状としては「時刻リセット」のほか、起動時に**BIOSのエラー画面**が出ることもあります
- 電池自体は数百円

### 交換について
デスクトップは比較的容易ですが、**ノートPCは分解が必要な機種が多く、難易度が上がります。**内部が両面テープで固定されていたり、電池がコネクタ接続だったりするためです。

自信がなければ無理に開けないことをおすすめします。**持ち込み診断は無料**ですので、まず状態を見せていただければ交換可否と費用をお伝えできます。

## 併せて確認したいこと

CMOS電池が切れるほどの年数が経っているパソコンは、他の部品も寿命に近づいています。この機会に次も点検しておくと安心です。

- ストレージの健康状態（HDDなら特に）
- 内部のホコリ、ファンの動作
- Windows 10のままになっていないか

「時計のずれ」がきっかけで診断したら、ストレージが末期だった——というケースは実際にあります。
